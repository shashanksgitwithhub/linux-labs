# Theory

## What is Linux?

Linux is a free and open-source operating system based on Unix. It acts as an interface between computer hardware and software applications while efficiently managing system resources such as CPU, memory, storage, and networking.

Linux is widely used in servers, cloud platforms, embedded systems, mobile devices, and enterprise environments because of its stability, security, and flexibility.

---

## What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and provides services for application software.

Examples:

- Linux
- Windows
- macOS
- Android
- iOS

Without an operating system, users cannot interact with computer hardware.

---

## History of Linux

- Created by **Linus Torvalds** in **1991**
- Inspired by the Unix Operating System
- Released as an Open Source project
- Continuously maintained by developers around the world

Today, Linux powers millions of servers and cloud infrastructures worldwide.

---

## What is Open Source?

Open Source software allows anyone to:

- View the source code
- Modify the source code
- Improve the software
- Redistribute it

Benefits:

- Free to use
- Highly secure
- Community-driven development
- Frequent updates

---

### Hardware

The physical components of a computer.

Examples:

- CPU
- RAM
- Hard Disk
- Keyboard
- Mouse
- Network Interface Card

---

### Kernel

The Kernel is the core component of Linux.

Responsibilities:

- Process Management
- Memory Management
- Device Management
- File System Management
- Network Management
- Security

---

### Shell

The Shell acts as an interface between the user and the Linux Kernel.

Popular Linux shells include:

- Bash
- Zsh
- Fish
- Ksh

Users execute commands through the Shell.

---

## Linux Distributions

A Linux Distribution (Distro) is a complete operating system built using the Linux Kernel.

Popular Linux distributions:

- Ubuntu
- Debian
- Red Hat Enterprise Linux (RHEL)
- Fedora
- CentOS
- Rocky Linux
- AlmaLinux
- Amazon Linux

---

## Why Linux is Used in Cloud Computing

Linux is the preferred operating system for cloud environments because it is:

- Open Source
- Stable
- Secure
- Lightweight
- Highly customizable
- Excellent for automation

Major cloud providers support Linux:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

---

## Linux in DevOps

Linux plays a vital role in DevOps because engineers use it to:

- Manage servers
- Deploy applications
- Configure web servers
- Write Bash scripts
- Automate tasks
- Monitor systems
- Run Docker and Kubernetes
